# Blinkit Data Analysis

A data analysis project focused on **Blinkit's sales performance, customer satisfaction, and inventory distribution**, using KPIs and visualizations to identify business insights and opportunities for optimization.

## Overview

The analysis covers:

* Data exploration and data types
* Data cleaning
* Key performance indicators (KPIs)
* Sales by item fat content
* Sales by item type
* Fat content by outlet location type
* Sales by outlet establishment year
* Sales by outlet size
* Sales by outlet location type

## KPIs

The project calculates:

* **Total Sales**
* **Average Sales**
* **Number of Items Sold**
* **Average Rating**

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The analysis uses a Blinkit sales dataset containing information such as item type, fat content, sales, rating, outlet size, outlet location, and outlet establishment year.

Dataset:

`blinkit_data.csv`
